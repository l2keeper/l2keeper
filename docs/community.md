# Community

L2Keeper is a small open-source project. Questions, bug reports, real-world
feedback, and pull requests are all welcome.

## Get help and share feedback

- [GitHub Discussions](https://github.com/l2keeper/l2keeper/discussions) — usage
  questions, ideas, show-and-tell, and design discussions.
- [GitHub Issues](https://github.com/l2keeper/l2keeper/issues) — reproducible bugs
  and concrete feature requests.
- [ROADMAP.md](https://github.com/l2keeper/l2keeper/blob/master/ROADMAP.md) — what is
  done, what is planned, and what is intentionally out of scope.

## Contribute

- [CONTRIBUTING.md](https://github.com/l2keeper/l2keeper/blob/master/CONTRIBUTING.md)
  — development setup, tests, lint, and PR expectations.
- [CODE_OF_CONDUCT.md](https://github.com/l2keeper/l2keeper/blob/master/CODE_OF_CONDUCT.md)
  — community behavior.
- [SECURITY.md](https://github.com/l2keeper/l2keeper/blob/master/SECURITY.md) — report
  vulnerabilities privately.
- [ADOPTERS.md](https://github.com/l2keeper/l2keeper/blob/master/ADOPTERS.md) — add
  your organization if you use L2Keeper.

## Spread the word

If L2Keeper replaces ServiceLB or MetalLB L2 in your cluster, useful things to
share:

- a short post with your cluster shape (k3s/RKE2, node count, ingress/Gateway
  API) and what improved;
- a comparison with your previous setup (source IP, `svclb` overhead, VIP
  failover);
- an example values file for your ingress or Gateway implementation.

Please avoid publishing private addresses, tokens, or customer names without
permission.
